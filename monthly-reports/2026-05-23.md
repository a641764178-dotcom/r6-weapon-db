## 5. 🆕 重要规律发现（本月）

### 5.1 霰弹枪 4m vs 5m 峰值规则

GitHub 实测霰弹枪在 **4m 处的伤害值通常 ≥ 5m 值**：
- M870: 4m=未列（推测>40），5m=40，灰机面板=42
- ITA12L: 4m=未列（推测>40），5m=40，灰机面板=41
- Super Shorty: 4m=35，5m=33
- Bailiff 410: 4m=30，5m=27
- Skeleton Key: 4m=31，5m=29

data.js 历史上**统一取 4m/灰机wiki 面板峰值**作为 damage 字段，与玩家在游戏内看到的"武器面板伤害"对齐。

**操作规则（新订入 MEMORY.md）**：
- 录入霰弹枪 damage 字段时 → **优先用灰机wiki 比对表的面板伤害值**
- 验证时不要把 GitHub 5m 当作"应该值"
- 校准报告中 GitHub 5m 与 data.js damage 差 1-3 点的霰弹枪，应判为 P2 口径差异

### 5.2 育碧官方页面优先级再次确认

灰机wiki M870 / ITA12L 干员栏不全（M870 缺 Sentry，ITA12L 缺新干员），与 Recruit 干员漏录规则一致。**Recruit 干员（Striker/Sentry）+ 部分新干员（Skopos/Rauora/Denari）的武器分配，必须以育碧官方为准**。
